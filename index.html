How to read this

Every election is counted two ways. Equal votes: one person, one vote, like now. Educated ×5: an educated person's vote counts as five. Same voters, same ballots, two results.

Voters pick by weighing the two candidates. The good one is only slightly better, so other things easily tip people: the news they follow (every source leans a random way each election, even when nobody pays it), their party, and plain misjudgement. A whole village or a whole channel's audience can be pushed the same way at once, and that is what makes a group wrong together.

Every election is also replayed with no rigging from the same random draws, so the page can tell you exactly what the rigging changed.

5Over 1,000 elections, which count was harder to rig?

One election can be luck. Run a thousand with the same country and the same rigging, and count how many the rigging stole under each way of counting.

Every variable in the model
